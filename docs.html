WELCOME TO VANILLA

Getting started

vanilla brings moderation, music, server utilities, and community commands together. Start with the command library, then configure the text prefix if you plan to use prefix commands.

01Invite the bot

Add vanilla to your Discord server and grant the permissions needed by the features you want to use.

Add vanilla to Discord ↗
02Choose a command

Use slash commands from Discord, or use the text prefix configured for your bot.

03Explore features

Open the command browser to search categories, read command descriptions, and copy a command name.

HOW TO TALK TO VANILLA

Command types

The bot scripts include slash commands, text-prefix commands, hybrid commands, and a separate music command set.

/
Slash commandsStart with / and choose the command from Discord's command picker.

↔

♫

TEXT COMMANDS

Set your prefix

The bot uses the value of PREFIX before text commands. For example, if your prefix is !, run !play. You can set the prefix from the Commands menu; that value is saved in this browser to format copied commands.

Use the command library

Choose a category in the left rail, type in the search box to narrow the list, and select a command to reveal its description and aliases. Select a command to open its details.

QUICK CHECKS

Troubleshooting

My text command isn't responding

Check the prefix in the bot environment, confirm the message starts with it, and make sure the bot has the required Discord permissions.

I can't find a slash command

Check that the bot is online and that the command exists in the current command library. Newly registered commands may take a little time to appear in Discord.

Music doesn't start

Confirm the bot can join and speak in the voice channel, and review the bot's music connection settings and runtime logs.

Where do I find aliases?

Open a command in the library. Any aliases included in the bot scripts appear with the command details.
